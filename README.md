# Legacy Collection Analysis Widget

## Instructions for set up:

1. Download the source code zip file.
2. Extract the zip file using file explorer into your preferred directory.
3. Locate the Legacy Collection Analysis folder in that directory.
4. Locate the dist folder within the root folder, and run main.exe.
5. Only the first time, you will need to follow the setup instructions, for which you will need a WorldCat API Key, API secret, API scopes, and an Alma BibKey.
6. Subsequent running of the file will have the widget pop up automatically!
